# Agent instructions

Read `CLAUDE.md` for the development workflow and `docs/methodology.md` before changing metrics.

Use plain names. Preserve raw result positions, unknown facts, errors, and pricing uncertainty.
Never invent evidence, observed results, confirmed charges, or live API verification.

For the results website, use literal sentence-case headings. Do not add small all-caps
labels above headings, narrative slogans, or middle-dot separators. Show plain complexity
names while retaining release codes in saved data. Put the quality/cost chart first;
keep calculation details optional. Match Avina's dashboard typography and controls.
